Features

  • WYSIWYG ⌘/Ctrl + / Raw

    Switch modes without losing your place. Content stays in sync. Toolbar follows the mode.

  • Folder workspace

    Open a directory; the sidebar becomes a fast file browser. Tabs across the top, recent files in the menu.

  • Export to PDF

    One shortcut, native print pipeline, sane defaults. No headless browser dance.

  • Theming

    Light, dark, or follow the system. Persists between launches. Document and chrome match.

  • Zoom

    ⌘/Ctrl + scroll, or use the View menu. Levels from 50% to 300%, saved across sessions.

  • Native menus + shortcuts

    New, Open, Save, Save As, Close, all wired to the keys you already know. Mac and Windows look like they should.

Build it yourself

Hash Markup is MIT-licensed and the source is public. If you don't trust binaries from the internet, clone the repo and build your own copy. Instructions are in the README.

Heads up: early Windows releases are signed under a new publisher identity (David Soden) that hasn't accumulated SmartScreen reputation yet. The first download may show a "Windows protected your PC" warning. Click More info → Run anyway. Reputation builds with downloads over time.
